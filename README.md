### 🧩 Currently building

**DTAXO** — a multi-tenant US 1040 tax-automation platform ([dtaxo.ai](https://dtaxo.ai))

- Multi-tenant org model with plans, limits, usage metering and lifecycle automation
- AI document extraction → structured workbook/leadsheet generation
- Automated filing via orchestrated Windows worker pods (snapshot-based provisioning, ~3 min cold start)
- Real-time task status over MQTT, queue routing across multiple tax engines
- Third-party integrations: OneDrive, Monday.com, payment gateways
- Zero-open-issue SonarQube quality gate across frontend + backend

### 📈 Engineering principles

- **Production first** — real customer data, real money flows; stability over cleverness
- **Smallest safe change** — understand the flow before touching it
- **Quality gates, not vibes** — tests, static analysis, and SonarQube before "done"
- **Own it end-to-end** — if I build the feature, I ship the infra and watch it in prod
